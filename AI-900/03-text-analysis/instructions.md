# Instructions

## 1. Open Microsoft Foundry

- Open Microsoft Foundry and sign in with your Azure account.
- Open the required Foundry project.
- Wait until the project is ready.

## 2. Deploy a Model

- Go to **Discover → Models**.
- Search for **gpt-5-mini**.
- Select **Deploy** and use the default settings.
- Wait for the deployment to finish.

## 3. Summarize Text

- Open the model in the **Chat Playground**.
- Change the instructions to:

  > You are an AI assistant that analyzes and summarizes text.

- Enter the provided **Commodore 64 review**.
- Ask the model to summarize it in a single short paragraph.
- Review the generated summary.

## 4. Explore Azure Language

- Go to **Build → Services**.
- Explore the available Azure Language services.
- Open **Azure Language – Language Detection**.
- Select a sample text and detect its language.
- Try entering your own text if needed.

## 5. Detect and Redact PII

- Open **Azure Language – Text PII Redaction**.
- Select a sample document.
- Run the PII detection.
- Review the detected information and the redacted text.
- Try your own text if required.

## 6. Review Sample Code

- Open the **Code** tab in the PII Redaction service.
- Review the provided Python code.
- Understand how the Azure Language client connects to the service and detects PII.

## 7. Complete the Lab

- Review the different features explored during the lab.
- Clean up any Azure resources that are no longer needed.

## ✅ Result

Successfully explored text summarization, language detection, PII detection and redaction, and Azure Language sample code in Microsoft Foundry.

## 🧹 Cleanup

Delete any Azure resources that are no longer needed to avoid unnecessary costs.
