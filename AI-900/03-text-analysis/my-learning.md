# My Learning – Text Analysis

## 🧠 What I Learned

In this lab, I got to explore how AI can be used to work with and
understand text in different ways.

I started with text summarization using a Generative AI model and then
explored Azure Language services for language detection and PII
detection and redaction.

This helped me understand that AI can do much more with text than just
generate a response. It can also analyze the information, identify
patterns, and help protect sensitive data.

## 💭 My Experience

I found this lab quite interesting because I got to see how the same
text can be used for completely different purposes.

For example, I could summarize a long piece of text, identify the
language it was written in, and also check whether it contained
sensitive information.

Working with these features practically helped me understand the
concepts much better than simply reading about them.

## 🔍 What I Found Interesting

The **PII detection and redaction** activity was the most interesting
part for me.

It was interesting to see how AI could identify sensitive information
within text and then automatically redact it. This made me understand
why protecting personal information is important when building
AI-powered applications.

I also found **language detection** useful because the service could
identify the language of the given text automatically.

## 💻 My Coding Experience

I also explored how these text analysis capabilities can be used with
Python.

I worked with examples for:

- Language detection
- PII detection and redaction

This gave me a better understanding of how Azure Language services can
be connected to an application and used programmatically instead of
only through the Microsoft Foundry interface.

- I understood the importance of protecting sensitive information.

Overall, this lab gave me a better understanding of the different ways
AI can work with text.
