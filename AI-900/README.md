# Microsoft Azure AI Fundamentals (AI-900)

## 📌 Overview

This repository contains my hands-on learning and practical lab work completed as part of the **Microsoft Azure AI Fundamentals (AI-900)** training.

The labs provided practical experience with **Microsoft Foundry**, generative AI, AI agents, text analysis, speech, computer vision, and information extraction.

## 🎯 Objectives

- Understand the fundamentals of Artificial Intelligence
- Explore Microsoft Azure AI services
- Work with Microsoft Foundry
- Explore generative AI and AI agents
- Analyze and process text
- Work with speech capabilities
- Analyze and generate images
- Generate videos using available AI models
- Extract information from documents and images
- Use Python SDKs and REST APIs to interact with Azure AI services

## 🛠️ Technologies & Services

## 🔬 Labs Completed

### 01. Get Started with Microsoft Foundry

Explored the Microsoft Foundry environment, created a project, explored the model catalog, tested models in the playground, and explored speech, computer vision, and text analysis capabilities.

**Folder:** `01-get-started-with-microsoft-foundry/`

### 02. Generative AI and AI Agents

Explored generative AI using a deployed model, tested prompts, used Web Search, and created and tested an AI agent.

**Folder:** `02-generative-ai-and-ai-agents/`

### 03. Text Analysis

Explored text analysis using generative AI and Azure Language services, including text summarization, language detection, and PII detection and redaction.

**Folder:** `03-text-analysis/`

### 04. Speech

Created a speech-enabled AI agent and explored Voice mode, speech input, speech output, speech recognition, speech synthesis, and conversation transcripts.

**Folder:** `04-speech/`

### 05. Computer Vision

Explored image analysis, image generation, and video generation using available models in Microsoft Foundry.

**Folder:** `05-computer-vision/`

### 06. Information Extraction

Explored Azure Content Understanding for OCR, document layout analysis, and receipt information extraction.

**Folder:** `06-information-extraction/`
