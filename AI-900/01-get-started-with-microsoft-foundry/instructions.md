# Instructions

## 1. Open Microsoft Foundry

- Open Microsoft Foundry and sign in with your Azure account.
- Open the required project or create a new one.
- Wait until the project is ready.

## 2. Explore the Project

Go through the main sections of the project:

- **Home** – View basic project information.
- **Discover** – Explore AI models and services.
- **Build** – Explore models, agents, tools, and AI solutions.
- **Operate** – View and manage project resources.
- **Docs** – Explore the available documentation.

## 3. Try the AI Assistant

- Open the AI assistant in the Foundry portal.
- Ask a simple question.
- Check the response.
- Try a few different questions.

## 4. Deploy an AI Model

- Open the model catalog.
- Select a chat model.
- Deploy the model.
- Open the model in the playground.
- Enter a prompt and check the response.
- Try a follow-up question.

## 5. Connect an AI Application

- Open the project details.
- Find the project connection information.
- Use the required details to configure the provided AI application.
- Save the configuration.
- Test the application with a few prompts.

### Explore AI Capabilities

#### 5.1 Generative AI

- Ask the AI questions on different topics.
- Try follow-up questions.
- Experiment with different prompts.
- Observe the generated responses.

#### 5.2 Text Analysis

- Provide some text to the AI.
- Ask it to summarize the content.
- Ask it to identify important information.
- Review the results.

#### 5.3 Speech

- Use the voice input feature.
- Allow microphone access if required.
- Speak a question.
- Check the speech-to-text result.
- Listen to the generated response.

#### 5.4 Computer Vision

- Upload an image.
- Ask the AI to describe or analyze it.
- Review the response.
- Try another image if available.

#### 5.5 Information Extraction

- Upload an image or document containing useful information.
- Ask the AI to identify important information.
- Review the extracted details.

## 6. Explore AI Safety

- Try different types of prompts.
- Observe how the AI responds to unsafe requests.
- Understand how safety filters help prevent harmful content.

## 7. Complete the Lab

- Review the different features explored during the lab.
- Delete any temporary Azure resources that are no longer needed to avoid unnecessary usage or charges.

## ✅ Result

Successfully explored Microsoft Foundry and practiced working with AI models, generative AI, text, speech, images, information extraction, and AI safety.

## 🧹 Cleanup

Delete any Azure resources that are no longer needed to avoid unnecessary costs.
