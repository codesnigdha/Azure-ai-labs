# My Learning – Generative AI and AI Agents

## 🧠 What I Learned

In this lab, I got my first hands-on experience with **Generative AI
models and AI agents** using Microsoft Foundry.

I learned how to deploy a Generative AI model, interact with it through
the Playground, and experiment with different prompts and instructions.

I also explored how additional tools, such as **Web Search**, can give
an AI model access to useful external information.

The most important thing I learned was the difference between simply
using an AI model and creating an **AI agent** that can be configured
with specific instructions and tools.

## 💭 My Experience

I really enjoyed this lab because it was the first time I got to
experiment with an AI agent in a practical way.

While interacting with the model in the Playground was already
interesting, creating an agent and seeing how it behaved based on the
instructions and tools I provided made the experience more meaningful
for me.

It helped me understand that an AI agent is not just about asking
questions and getting answers. It can be designed and configured for
specific purposes.

## 🔍 What I Found Interesting

The **Web Search** feature was one of the things I found most
interesting.

It showed me how an AI model can use additional tools to get information
beyond what it already knows, which can make its responses more useful.

I also enjoyed creating and testing the **AI agent**. Changing the
instructions and observing how the agent responded helped me understand
how an agent's behavior can be guided.

## 💻 My Coding Experience

Along with working through the Microsoft Foundry interface, I also
reviewed the Python code used to access the AI agent programmatically.

I worked with the **Azure AI Projects SDK** and learned how an
application can connect to a configured agent and send requests to it.

This gave me a better understanding of how the concepts I explored in
the Playground can be taken into an actual application through code.

## 📌 My Key Takeaways

- I learned how to deploy and interact with a Generative AI model.
- I practiced working with prompts and model instructions.
- I explored Web Search as an additional AI tool.
- I learned the basic concept of AI agents.
- I created and tested an AI agent in Microsoft Foundry.
- I explored how tools can extend an AI agent's capabilities.
- I reviewed Python code for interacting with an AI agent.
- I gained practical experience with the Azure AI Projects SDK.

## 🎯 My Overall Experience

Overall, this lab gave me a much better understanding of **Generative AI
and AI agents**.

What I liked most was being able to move from simply using an AI model
to actually **creating and configuring an agent**.

This lab made me more curious about how AI agents can be designed for
different tasks and how tools can be combined with AI models to build
more useful applications.
