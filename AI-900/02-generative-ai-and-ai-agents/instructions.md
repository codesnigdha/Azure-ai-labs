# Instructions

## 1. Open Microsoft Foundry

- Open Microsoft Foundry and sign in with your Azure account.
- Open the required Foundry project.
- Wait until the project is ready.

## 2. Deploy a Model

- Open the **Discover** section.
- Go to the **Models** tab.
- Search for **gpt-5-mini**.
- Open the model and select **Deploy**.
- Use the default deployment settings.
- Wait for the deployment to complete.

## 3. Chat with the Model

- Open the model in the **Playground**.
- Enter a question and review the response.
- Try a follow-up question to see how the model maintains conversation context.
- Start a new chat and try another prompt.

## 4. Configure Model Instructions

- Open the **Instructions** section.
- Add instructions that give the model a specific role.
- Test the instructions with relevant and unrelated questions.
- Observe how the model changes its responses based on the instructions.

## 5. Add Web Search

- Open the **Tools** section.
- Select **Add** and enable **Web search**.
- Start a new chat.
- Ask a question that requires current information.
- Review the response and observe how web search helps provide up-to-date information.

## 6. Add Knowledge

- Download the provided `vintage_computer_identifiers.docx` document.
- Upload the document in the **Tools** section.
- Create an index using the uploaded document.
- Attach the index to the model.
- Start a new chat.
- Ask questions related to information contained in the document.
- Review the response based on the uploaded knowledge.

## 7. Create an AI Agent

- Select **Save as agent**.
- Name the agent `computing-historian`.
- Save the model configuration as an agent.
- Check the agent's instructions and tools.
- Open the **Chat** tab and test the agent.
- Review the response.

## 8. Preview the Agent

- Open the **Publish** option.
- Select **Preview web app**.
- Test the agent in the web application.
- Enter a question and review the generated response.

## 9. View Client Code

- Open the agent's **Call agent** section.
- View the sample Python code provided by Microsoft Foundry.
- Review how the code connects to the Foundry project and accesses the agent.

## 10. Complete the Lab

- Review the different features explored during the lab.
- Clean up any temporary Azure resources that are no longer needed.

## ✅ Result

Successfully explored Microsoft Foundry by deploying and testing an AI model, configuring model instructions, using web search and uploaded knowledge, creating and testing an AI agent, previewing the agent in a web application, and reviewing the provided client code.

## 🧹 Cleanup

Delete any Azure resources that are no longer needed to avoid unnecessary costs.
